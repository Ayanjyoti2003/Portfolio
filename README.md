## ✨ Features
- **Premium Tech Aesthetic**: Dark-mode primary design with glassmorphic cards, neon accents, and clean Google Fonts (`Outfit`, `Inter`, `Fira Code`).
- **Responsive Layout**: Fully responsive interface that looks stunning on mobile devices, tablets, and desktops alike.
- **Component-Driven Architecture**: Built modularly with reusable React components (Hero, About, Skills, Experience, Projects).
- **Fast & Optimized**: Leverages Next.js App Router and Server/Client configurations for blazing-fast performance.

## 🛠️ Tech Stack
- **Framework**: [Next.js 15 (App Router)](https://nextjs.org/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: Context-aware Vanilla CSS with custom properties and layout classes.
- **Icons**: [React Icons](https://react-icons.github.io/react-icons/)
- **Deployment**: [Vercel](https://vercel.com/) (Planned)

## 💻 Running Locally

To run this project on your local machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Ayanjyoti2003/Portfolio.git
   cd Portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   # or yarn install / pnpm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **View the application:**
   Open [http://localhost:3000](http://localhost:3000) in your browser.

## 📁 Project Structure

```text
├── src/
│   ├── app/
│   │   ├── globals.css     # Global design system & theme variables
│   │   ├── layout.tsx      # Root layout and font definitions

│       ├── About.tsx       # Education & Certifications
│       ├── Skills.tsx      # Categorized tech-stack badges
│       ├── Experience.tsx  # Work history & Hackathons
│       ├── Projects.tsx    # Details on highlighted applications
│       ├── ProjectCard.tsx # Reusable card UI for projects
│       └── Footer.tsx      # Bottom navigation & copyright
```
